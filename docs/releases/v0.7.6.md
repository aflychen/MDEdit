# MDEdit v0.7.6

<a name="release-notes-chinese"></a>

## 简体中文

修复编辑区拖动选中文字时，高亮被当前行背景遮住的问题。触摸板三指拖动和普通拖动现在都能清楚显示选区，所选文字仍可用 ⌘C 复制。浅色与深色主题均已调整。

> **macOS 特别说明：** `MDEdit-0.7.6-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

Fixed the active-line background hiding selected text in the editor. Selections made with three-finger trackpad dragging or ordinary dragging are now visible and remain copyable with ⌘C. The fix covers light and dark themes.

> **macOS notice:** `MDEdit-0.7.6-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
