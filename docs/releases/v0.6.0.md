# MDEdit v0.6.0

<a name="release-notes-chinese"></a>

## 简体中文

此版本完善长文写作和 GFM 表格编辑。

> **macOS 特别说明：** `MDEdit-0.6.0-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 新增可独立切换的专注模式与打字机模式。专注模式淡化当前段落以外的编辑行；打字机模式在输入时将光标行保持在编辑区中部。
- 目录支持当前章节高亮、标题筛选和层级折叠。筛选时会显示匹配标题的上级路径。
- GFM 表格支持 Tab / Shift+Tab 单元格导航、在末尾追加正文行，以及增删行列和设置列对齐。

表格结构命令只作用于顶层 GFM 表格。对于嵌套表格或正文行含额外单元格的表格，应用不会改写原始 Markdown。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。macOS DMG 是临时签名试用包，不等同于可直接通过 Gatekeeper 的正式签名安装包。

<a name="release-notes-english"></a>

## English

This release improves long-form writing and GFM table editing.

> **macOS notice:** `MDEdit-0.6.0-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it to run after download. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- Focus mode and typewriter mode can be toggled independently. Focus mode dims lines outside the current paragraph; typewriter mode keeps the caret line near the middle of the editor while typing.
- The outline highlights the current section and supports heading search and hierarchy collapse. Search results include the matching heading's ancestors.
- GFM tables support Tab / Shift+Tab cell navigation, appending a body row at the end, row and column operations, and column alignment.

Structural table commands apply only to top-level GFM tables. Nested tables and tables with surplus cells in a body row are left unchanged.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`. The macOS DMG is a trial package and does not pass Gatekeeper as a Developer ID signed installer.
