# MDEdit v0.3.0

本版本增加文件夹工作区、跨文件搜索、深色模式和更多列表格式。

> **macOS 特别说明：** `MDEdit-0.3.0-arm64-adhoc.dmg` 是临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开。请只在确认文件来源可信时尝试系统的手动允许操作；如仍提示“已损坏”，请在本机从源码构建。

## 新功能

- 通过系统对话框选择本地文件夹，在左侧文件树中按需展开子文件夹并打开 Markdown 文档；当前标签对应的文件会突出显示。
- 在所选文件夹内搜索 Markdown 文本。结果显示相对路径、命中片段和行号；文件版本与搜索时一致、命中行未变时，点击后定位到对应位置，否则提示重新搜索。
- 外观支持跟随系统、浅色和深色，偏好保存在本机。
- 工具栏支持将当前行或选中的多行转换为无序列表、数字有序列表或任务列表；有序列表按层级连续编号。

## 范围与限制

- 文件夹树只提供浏览和打开，不提供重命名、移动或删除。文件夹授权在本次应用会话内有效，文件树和搜索不跟随符号链接。
- 搜索最多显示 100 条结果；超过 5 MiB、无法读取或不是有效 UTF-8 的文件会被跳过，并显示跳过数量。
- 文件访问会校验真实路径和符号链接；若其他本地进程在读写期间持续替换目录，仍可能存在路径竞态。请勿将此版本作为抵御同机恶意进程的安全隔离机制。
- macOS DMG 面向 Apple 芯片 Mac，属于临时签名试用包；Windows `.exe` 由 Windows 构建环境生成。正式 macOS 发行仍需 Developer ID 签名和 Apple 公证。
