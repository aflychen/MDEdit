# MDEdit v0.7.1

<a name="release-notes-chinese"></a>

## 简体中文

此版本重做了文档内查找与替换面板，并为应用界面加入 English 与简体中文。首次安装以及没有有效语言偏好时默认 English；在“视图 → 语言”中可立即切换，选择会在重启后保留。

> **macOS 特别说明：** `MDEdit-0.7.1-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 新搜索面板将查找输入、前后跳转、大小写、正则、整词与按需展开的替换操作清晰分组；在最小窗口尺寸、侧栏和预览同时显示时仍可操作。
- 继续支持 `Cmd/Ctrl+F`、Enter、Shift+Enter、Esc、单次替换和全部替换。切换语言时保留当前查询、替换内容和编辑位置；错误正则会显示提示并禁用替换。
- 菜单、工具栏、标签、草稿恢复、侧栏、状态栏、预览占位、应用提示与错误支持双语。新插入表格的默认表头随当前语言生成；已有文档内容、文件名和路径保持原样。
- 新建文档的默认保存名、导出页面语言和应用生成的错误提示也随语言设置变化。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。macOS DMG 是临时签名试用包，不等同于可直接通过 Gatekeeper 的正式签名安装包。

<a name="release-notes-english"></a>

## English

This release redesigns Find and Replace and adds English and Simplified Chinese across the app interface. A fresh installation, or an installation without a valid language preference, starts in English. Change the language in View → Language; the choice takes effect immediately and persists across restarts.

> **macOS notice:** `MDEdit-0.7.1-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it to run after download; if macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- The new search panel groups the find field, previous/next navigation, case, regular expression, whole-word options, and an expandable replacement row. Every action remains accessible at the minimum window size with the sidebar and preview open.
- `Cmd/Ctrl+F`, Enter, Shift+Enter, Escape, Replace, and Replace All continue to work. Switching languages keeps the current query, replacement text, and editor position. Invalid regular expressions show a message and disable replacement.
- Menus, toolbar, tabs, draft recovery, sidebar, status, preview placeholders, app notices, and errors are available in both languages. Newly inserted table headers use the selected language; existing document content, names, and paths stay unchanged.
- The default name for a new document, exported page language, and app generated errors follow the selected language.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`. The macOS DMG is a trial package and does not pass Gatekeeper as a Developer ID signed installer.
