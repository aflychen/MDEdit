# MDEdit v0.1.0

首个可试用版本，支持本地 Markdown 编辑、实时预览、自动保存、磁盘冲突提示和恢复草稿。

## 安装包

- `MDEdit-0.1.0-arm64.dmg`：Apple 芯片 Mac。打开 DMG 后将 MDEdit 拖入“应用程序”。
- `.exe` 安装包：64 位 Windows，由 GitHub Actions 在 Windows 环境构建。
- `SHA256SUMS`：上述安装包的 SHA-256 校验值。

macOS 安装包尚未签名和公证，首次打开可能需要在系统中手动允许。Windows 安装包仍需实机安装与运行验证。

## English

The first trial release, with local Markdown editing, live preview, automatic saving, disk conflict warnings, and recovery drafts.

### Installers

- `MDEdit-0.1.0-arm64.dmg`: for Apple silicon Macs. Open the DMG and drag MDEdit to Applications.
- `.exe` installer: for 64-bit Windows, built by GitHub Actions on Windows.
- `SHA256SUMS`: SHA-256 checksums for the installers above.

The macOS installer is not signed or notarized, so you may need to allow it manually in system settings the first time you open it. The Windows installer still needs to be installed and run on a real Windows machine for verification.
