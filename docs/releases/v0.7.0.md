# MDEdit v0.7.0

<a name="release-notes-chinese"></a>

## 简体中文

此版本为 PDF 导出增加页面设置，方便按不同纸张和章节结构分享文档。

> **macOS 特别说明：** `MDEdit-0.7.0-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 在“文件”菜单中选择 A4、A5 或 Letter 纸张，以及窄 10 mm、标准 18 mm 或宽 25 mm 页边距；设置会记住上次选择。
- 可让正文中的一级标题从新页开始。默认仍为 A4、18 mm 页边距且不强制分页。
- PDF 继续导出当前标签的最新内容，保留已支持的本地图片、表格、代码高亮、Mermaid 图表和公式。HTML 导出行为不变。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。macOS DMG 是临时签名试用包，不等同于可直接通过 Gatekeeper 的正式签名安装包。

<a name="release-notes-english"></a>

## English

This release adds page settings to PDF export for different paper formats and chapter layouts.

> **macOS notice:** `MDEdit-0.7.0-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it to run after download; if macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- Choose A4, A5, or Letter paper and narrow 10 mm, standard 18 mm, or wide 25 mm margins in the File menu. The app remembers the last selection.
- Optionally start each later level-one heading on a new page. A4, 18 mm, and no forced heading breaks remain the defaults.
- PDF export still uses the current tab's latest content and retains supported local images, tables, highlighted code, Mermaid diagrams, and math. HTML export is unchanged.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`. The macOS DMG is a trial package and does not pass Gatekeeper as a Developer ID signed installer.
