# MDEdit v0.2.0

<a name="release-notes-chinese"></a>

## 简体中文

本版本增加多文档工作区和 Markdown 编辑辅助功能。

### 新功能

- 使用多个标签同时编辑文档；每个标签独立保留编辑位置、保存状态、恢复草稿和磁盘冲突状态。
- 根据当前文档的 H1～H6 标题生成可点击的大纲，并同步编辑区与预览区的位置。
- 为显式标记语言的代码块提供语法高亮；支持 highlight.js 注册语言，未标记或无法识别的语言显示普通文本。
- 工具栏支持正文、H1～H5、GFM 表格、列表、任务项、引用和围栏代码块。
- 预览代码块可复制；同一文档路径重复打开时聚焦已有标签。

### 安装包

- `.dmg`：Apple 芯片 Mac。
- `.exe`：64 位 Windows 安装程序。
- `SHA256SUMS`：安装包的 SHA-256 校验值。

macOS 安装包尚未签名和公证，首次打开可能需要在系统中手动允许。

<a name="release-notes-english"></a>

## English

This release adds a multi-document workspace and Markdown editing helpers.

### New features

- Edit multiple documents in tabs. Each tab keeps its own cursor position, save status, recovery draft, and disk conflict state.
- Generate a clickable outline from the current document's H1–H6 headings and keep the editor and preview positions synchronized.
- Syntax highlighting for code blocks with an explicit language label. Registered highlight.js languages are supported; unlabeled or unrecognized languages are shown as plain text.
- The toolbar supports body text, H1–H5, GFM tables, lists, task items, quotes, and fenced code blocks.
- Copy preview code blocks, and focus an existing tab when opening a document path that is already open.

### Installers

- `.dmg`: for Apple silicon Macs.
- `.exe`: 64-bit Windows installer.
- `SHA256SUMS`: SHA-256 checksums for the installers.

The macOS installer is not signed or notarized, so you may need to allow it manually in system settings the first time you open it.
