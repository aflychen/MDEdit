# MDEdit v0.7.4

<a name="release-notes-chinese"></a>

## 简体中文

“可恢复草稿”列表现可删除单条草稿，或一次清空全部草稿。两种删除操作都会先请求确认；取消时不作改动。删除仅作用于应用保存的恢复草稿，不删除磁盘上的 Markdown 文件。若草稿在确认后更新，较新的备份会保留并重新显示。

> **macOS 特别说明：** `MDEdit-0.7.4-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

The Recoverable Drafts list now lets you delete one draft or clear all drafts. Both actions ask for confirmation, and canceling leaves drafts unchanged. Deletion affects only the app's recovery backups, not Markdown files on disk. A newer backup created after confirmation is preserved and shown again.

> **macOS notice:** `MDEdit-0.7.4-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
