# MDEdit v0.6.2

<a name="release-notes-chinese"></a>

## 简体中文

此版本改进恢复草稿入口，让多份未命名草稿更容易查找，同时避免提示条占用编辑空间。

> **macOS 特别说明：** `MDEdit-0.6.2-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 将横向滚动的恢复提示条改为标签栏右侧的草稿数量入口，不再增加单独一行。
- 草稿列表按修改时间排列，未命名草稿显示正文摘要，同名文件草稿显示所在目录；列表高度受窗口限制，可滚动查看。
- 关闭草稿列表不会清除恢复入口或草稿；点击条目后仍按原有安全恢复流程打开文档。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。macOS DMG 是临时签名试用包，不等同于可直接通过 Gatekeeper 的正式签名安装包。

<a name="release-notes-english"></a>

## English

This release makes recovery drafts easier to find without using a full-width banner above the editor.

> **macOS notice:** `MDEdit-0.6.2-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it to run after download; if macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- A draft count control on the tab bar replaces the horizontally scrolling recovery strip.
- Drafts remain sorted by modification time. Unnamed drafts show a content preview, while named drafts show their folder to distinguish files with the same name. The height-limited list scrolls when needed.
- Closing the list keeps drafts available; choosing an item uses the existing safe recovery flow.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`. The macOS DMG is a trial package and does not pass Gatekeeper as a Developer ID signed installer.
