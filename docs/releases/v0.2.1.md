# MDEdit v0.2.1

<a name="release-notes-chinese"></a>

## 简体中文

本版本更新 MDEdit 应用图标，采用带折角的 Markdown 文档造型，并在图标中突出 MDE 字母。

> **macOS 特别说明：** 本页的 `MDEdit-0.2.1-arm64-adhoc.dmg` 是临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开。请只在确认文件来源可信时尝试系统的手动允许操作；如仍提示“已损坏”，请在本机从源码构建。原始签名不完整的 DMG 已撤下。

### 安装包

- `MDEdit-0.2.1-arm64-adhoc.dmg`：Apple 芯片 Mac 临时签名试用包。
- `.exe`：64 位 Windows 安装程序。
- `SHA256SUMS`：以上两个安装包的 SHA-256 校验值。

临时签名包已通过 DMG 完整性校验和应用签名校验，并已在构建它的 Mac 上启动；Gatekeeper 评估仍为拒绝。它不是可直接双击安装的正式 macOS 发行版。

<a name="release-notes-english"></a>

## English

This release updates the MDEdit app icon to a folded-corner Markdown document design with the letters MDE highlighted.

> **macOS notice:** `MDEdit-0.2.1-arm64-adhoc.dmg` is an ad hoc signed trial build. It has not been signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it, and it may not open directly after download. Only try manually allowing it in system settings if you trust the file's source. If macOS still says it is damaged, build from source on your Mac. The DMG with an incomplete original signature has been withdrawn.

### Installers

- `MDEdit-0.2.1-arm64-adhoc.dmg`: ad hoc signed trial build for Apple silicon Macs.
- `.exe`: 64-bit Windows installer.
- `SHA256SUMS`: SHA-256 checksums for the two installers above.

The trial build passed DMG integrity and app signature checks, and it launched on the Mac that built it; Gatekeeper still rejects it. It is not a proper macOS release that can be installed by double-clicking.
