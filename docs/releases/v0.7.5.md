# MDEdit v0.7.5

<a name="release-notes-chinese"></a>

## 简体中文

修复“插入 → 表格”中列数和正文行数输入框的显示问题。删除原有数字后，输入框现在会保持空白，重新输入时不会在数字前自动加上 `0`。原有的必填和数值范围校验仍然适用。

> **macOS 特别说明：** `MDEdit-0.7.5-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

Fixed the column and body row inputs under Insert → Table. Clearing an existing value now leaves the field empty, and entering a new number no longer adds a leading `0`. The required field and range checks still apply.

> **macOS notice:** `MDEdit-0.7.5-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
