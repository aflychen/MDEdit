# MDEdit v0.5.0

<a name="release-notes-chinese"></a>

## 简体中文

本版本增加当前文档的 HTML 和 PDF 导出。

**macOS 安装包已确认无法启动。请使用 [v0.5.1](https://github.com/aflychen/MDEdit/releases/tag/v0.5.1) 的修复版安装包。**

> **macOS 特别说明：** `MDEdit-0.5.0-arm64-adhoc.dmg` 是临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开。请只在确认文件来源可信时尝试系统的手动允许操作；如仍提示“已损坏”，请在本机从源码构建。

### 新功能

- 顶部按钮可将当前标签的最新编辑内容导出为独立 HTML 文件或 A4 PDF。
- 导出保留 GFM 表格、代码高亮、本地图片、Mermaid 图表及行内和块级公式。
- HTML 内嵌图片、图表 SVG、样式和公式字体，移动单个文件后仍可打开。

### 范围与限制

- 两种格式统一使用浅色阅读样式；远程图片不自动加载，继续显示占位提示。
- 本地图片必须能从已保存的 Markdown 文档目录读取；读取失败会停止导出并提示原因。未命名文档如不含本地图片仍可直接导出。
- macOS DMG 面向 Apple 芯片 Mac，属于临时签名试用包；Windows `.exe` 由 Windows 构建环境生成。`SHA256SUMS` 列出安装包校验值。

<a name="release-notes-english"></a>

## English

This release adds HTML and PDF export for the current document.

**The macOS installer is confirmed not to launch. Use the fixed installer from [v0.5.1](https://github.com/aflychen/MDEdit/releases/tag/v0.5.1).**

> **macOS notice:** `MDEdit-0.5.0-arm64-adhoc.dmg` is an ad hoc signed trial build. It has not been signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it, and it may not open directly after download. Only try manually allowing it in system settings if you trust the file's source. If macOS says it is damaged, build from source on your Mac.

### New features

- Use the top buttons to export the latest content in the current tab as a standalone HTML file or A4 PDF.
- Exports preserve GFM tables, code highlighting, local images, Mermaid diagrams, and inline and block formulas.
- The HTML file embeds images, diagram SVGs, styles, and formula fonts, so it remains usable if moved on its own.

### Scope and limitations

- Both formats use a light reading style. Remote images are not loaded automatically and continue to show a placeholder notice.
- Local images must be readable from the saved Markdown document's directory. If reading one fails, export stops and explains why. An unnamed document can still be exported directly if it contains no local images.
- The macOS DMG is for Apple silicon Macs and is an ad hoc signed trial build. The Windows `.exe` is built on Windows. `SHA256SUMS` lists installer checksums.
