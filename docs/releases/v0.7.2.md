# MDEdit v0.7.2

<a name="release-notes-chinese"></a>

## 简体中文

此版本让常用界面设置更容易找到，并增加真正的纯预览阅读模式。

> **macOS 特别说明：** `MDEdit-0.7.2-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 顶栏增加独立的语言按钮，一键在 English 与简体中文间切换；首次安装默认英文，选择会在重启后保留。
- 文档内查找使用更大的放大镜图标和点击区域。
- 工具栏提供“编辑 / 双栏 / 预览”三种布局，双栏同时显示编辑与预览。纯预览隐藏源码编辑区与格式工具栏；切回编辑或双栏时保留文档内容和编辑状态。在纯预览中打开文档内查找或跨文件搜索结果会切到双栏，以显示搜索位置。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

This release makes common display controls easier to find and adds a reading layout that shows only the preview.

> **macOS notice:** `MDEdit-0.7.2-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- A dedicated button in the top bar switches between English and Simplified Chinese. New installations start in English, and the choice persists across restarts.
- Find in Document has a larger magnifying glass icon and click target.
- The toolbar now offers Edit, Split, and Preview layouts. Split shows the editor and preview side by side. Preview hides the source editor and formatting toolbar; returning to Edit or Split retains document content and editor state. Opening Find in Document or a workspace search result from Preview switches to Split so the search location is visible.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
