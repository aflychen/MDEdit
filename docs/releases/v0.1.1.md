# MDEdit v0.1.1

## 简体中文

首个安装包发布版本。提供本地 Markdown 编辑、实时预览、自动保存、磁盘冲突提示和恢复草稿。

此版本修正了 Windows 测试对 POSIX 文件权限的假设；保存前后的权限仍会按当前平台报告的值进行检查。

### 安装包

- `.dmg`：Apple 芯片 Mac。打开后将 MDEdit 拖入“应用程序”。
- `.exe`：64 位 Windows 安装程序。
- `SHA256SUMS`：安装包的 SHA-256 校验值。

macOS 安装包尚未签名和公证，首次打开可能需要在系统中手动允许。Windows 安装包由 Windows 构建环境生成，仍需实机安装和运行验证。

## English

The first installer release. It provides local Markdown editing, live preview, automatic saving, disk conflict warnings, and recovery drafts.

This version fixes a Windows test that assumed POSIX file permissions. Permissions are still checked against the values reported by the current platform before and after saving.

### Installers

- `.dmg`: for Apple silicon Macs. Open it and drag MDEdit to Applications.
- `.exe`: 64-bit Windows installer.
- `SHA256SUMS`: SHA-256 checksums for the installers.

The macOS installer is not signed or notarized, so you may need to allow it manually in system settings the first time you open it. The Windows installer is built on Windows and still needs to be installed and run on a real machine for verification.
