# MDEdit v0.6.1

<a name="release-notes-chinese"></a>

## 简体中文

此版本整理写作界面，减少顶部操作密度并改善正文可读性。原有文档能力和快捷键保持不变。

> **macOS 特别说明：** `MDEdit-0.6.1-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

- 顶栏保留新建、打开和保存；打开文件夹、另存为、导出及最近文件移入“文件”菜单。文件名由标签展示，保存状态留在顶栏。
- 格式栏保留标题、粗体、斜体和链接；列表、表格、引用、代码等操作归入“插入”菜单。专注模式、打字机模式和主题选择移入“视图”菜单。
- 提高编辑区与侧栏的字号，为单栏编辑和预览正文设置合适的阅读宽度，并精简重复标题和分隔样式。
- 菜单支持键盘操作与 Escape 关闭；浅色和深色主题均包含对应的菜单、悬停、选中及焦点状态。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。macOS DMG 是临时签名试用包，不等同于可直接通过 Gatekeeper 的正式签名安装包。

<a name="release-notes-english"></a>

## English

This release simplifies the writing interface and improves text readability. Existing document features and shortcuts remain available.

> **macOS notice:** `MDEdit-0.6.1-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it to run after download; if macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

- The top bar keeps New, Open, and Save. Open Folder, Save As, export, and recent files are in the File menu. Tabs show document names while save status stays visible in the top bar.
- Heading, bold, italic, and link controls remain on the toolbar. Lists, tables, quotes, and code commands are in Insert; Focus mode, Typewriter mode, and theme selection are in View.
- Editor and sidebar text is larger. The single-pane editor and preview use comfortable reading widths, with fewer repeated labels and separators.
- Menus support keyboard access and Escape to close. Light and dark themes include matching menu, hover, selected, and focus states.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`. The macOS DMG is a trial package and does not pass Gatekeeper as a Developer ID signed installer.
