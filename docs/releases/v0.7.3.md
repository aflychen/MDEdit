# MDEdit v0.7.3

<a name="release-notes-chinese"></a>

## 简体中文

修正顶栏语言切换按钮的文案：英文界面显示“中文”，中文界面显示“English”，明确表示点击后的目标语言。现有语言选择与重启后的持久化行为保持一致。

> **macOS 特别说明：** `MDEdit-0.7.3-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

The top-bar language switch now names the language it will switch to: “中文” in the English interface and “English” in the Chinese interface. Language selection and persistence across restarts continue to work as before.

> **macOS notice:** `MDEdit-0.7.3-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
