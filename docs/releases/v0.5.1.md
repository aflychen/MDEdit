# MDEdit v0.5.1

本补丁修复 v0.5.0 macOS 临时签名安装包双击后立即退出的问题。v0.5.0 中 Hardened Runtime 阻止主程序加载 Electron Framework；v0.5.1 为临时签名包单独配置所需的库验证权限，并在打包时确认权限已写入签名。

> **macOS 特别说明：** `MDEdit-0.5.1-arm64-adhoc.dmg` 仍是临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 可能阻止直接打开；正式发行仍需 Developer ID 签名与 Apple 公证。

## 下载

- `MDEdit-0.5.1-arm64-adhoc.dmg`：Apple 芯片 Mac 临时签名试用包。
- `MDEdit.Setup.0.5.1.exe`：Windows x64 安装包。
- `SHA256SUMS`：两个安装包的 SHA-256 校验值。

功能与 v0.5.0 相同：支持导出包含本地图片、Mermaid、公式、表格和代码高亮的单文件 HTML 与 A4 PDF。

## English

This patch fixes the v0.5.0 macOS ad hoc signed installer, which exited immediately after launch. In v0.5.0, Hardened Runtime prevented the main process from loading Electron Framework. For the ad hoc signed build, v0.5.1 separately configures the required library validation permission and verifies during packaging that the permission is included in the signature.

> **macOS notice:** `MDEdit-0.5.1-arm64-adhoc.dmg` is still an ad hoc signed trial build. It has not been signed with a Developer ID or notarized by Apple. Gatekeeper may block it from opening directly. A proper release still requires Developer ID signing and Apple notarization.

### Downloads

- `MDEdit-0.5.1-arm64-adhoc.dmg`: ad hoc signed trial build for Apple silicon Macs.
- `MDEdit.Setup.0.5.1.exe`: Windows x64 installer.
- `SHA256SUMS`: SHA-256 checksums for both installers.

Features are the same as v0.5.0: export a single-file HTML document containing local images, Mermaid diagrams, formulas, tables, and code highlighting, or export an A4 PDF.
