# MDEdit v0.4.0

## 简体中文

本版本增加图片粘贴与拖入、Mermaid 图表和数学公式预览。

> **macOS 特别说明：** `MDEdit-0.4.0-arm64-adhoc.dmg` 是临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行，下载后可能无法直接打开。请只在确认文件来源可信时尝试系统的手动允许操作；如仍提示“已损坏”，请在本机从源码构建。

### 新功能

- 在编辑区粘贴或拖入 PNG、JPEG、GIF、WebP、AVIF 图片，自动保存到当前 Markdown 文档同级的 `images/` 目录，并插入相对路径。可一次导入多张；未命名文档先选择保存位置。
- 预览中渲染 `mermaid` 围栏代码块，并随明暗主题更新配色。图表语法错误显示在对应位置。
- 预览中渲染 `$...$` 行内公式和 `$$...$$` 块级公式；公式语法错误不影响其余文档内容。

### 范围与限制

- 单张图片不超过 10 MiB；每次最多导入 20 张，总大小不超过 50 MiB。图片保存后只在全部写入成功时插入 Markdown 链接；导入失败时会尝试清理本批已创建的文件。
- 本地图片仍只预览当前文档目录及其子目录内的相对路径，远程图片不自动加载。
- macOS DMG 面向 Apple 芯片 Mac，属于临时签名试用包；Windows `.exe` 由 Windows 构建环境生成。正式 macOS 发行仍需 Developer ID 签名和 Apple 公证。

## English

This release adds pasting and dragging images into documents, Mermaid diagrams, and math formula previews.

> **macOS notice:** `MDEdit-0.4.0-arm64-adhoc.dmg` is an ad hoc signed trial build. It has not been signed with a Developer ID or notarized by Apple. Gatekeeper will not automatically allow it, and it may not open directly after download. Only try manually allowing it in system settings if you trust the file's source. If macOS says it is damaged, build from source on your Mac.

### New features

- Paste or drag PNG, JPEG, GIF, WebP, and AVIF images into the editor. Images are saved in an `images/` folder alongside the current Markdown document, and relative paths are inserted. Multiple images can be imported at once; for an unnamed document, choose where to save it first.
- Render `mermaid` fenced code blocks in the preview, with colors that follow the light or dark theme. Diagram syntax errors are shown at the relevant location.
- Render `$...$` inline formulas and `$$...$$` block formulas in the preview. A formula syntax error does not affect the rest of the document.

### Scope and limitations

- Each image must be no larger than 10 MiB. Each import can contain up to 20 images with a combined size of at most 50 MiB. Markdown links are inserted only after all images have been written successfully; if an import fails, the app attempts to remove files created in that batch.
- Local images are previewed only when referenced by a relative path within the current document's directory or its subdirectories. Remote images are not loaded automatically.
- The macOS DMG is for Apple silicon Macs and is an ad hoc signed trial build. The Windows `.exe` is built on Windows. A proper macOS release still requires Developer ID signing and Apple notarization.
