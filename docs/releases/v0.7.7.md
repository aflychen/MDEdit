# MDEdit v0.7.7

<a name="release-notes-chinese"></a>

## 简体中文

加深编辑区选中文字时的高亮颜色，并减轻当前行底色对选区的遮盖。触摸板三指拖动、普通拖动和键盘选择的文字在浅色与深色主题中更容易辨认，复制粘贴行为不变。

> **macOS 特别说明：** `MDEdit-0.7.7-arm64-adhoc.dmg` 是 Apple 芯片 Mac 的临时签名试用包，未经 Developer ID 签名和 Apple 公证。Gatekeeper 不会自动放行；如系统拒绝启动，请在本机从源码构建，或等待正式签名和公证的版本。

发布附件包含 macOS DMG、Windows 安装程序和 `SHA256SUMS` 校验文件。

<a name="release-notes-english"></a>

## English

Strengthened the editor selection highlight and reduced the active-line tint over selected text. Text selected by three-finger trackpad dragging, ordinary dragging, or the keyboard is easier to see in light and dark themes. Copy and paste behavior is unchanged.

> **macOS notice:** `MDEdit-0.7.7-arm64-adhoc.dmg` is an ad hoc signed trial build for Apple silicon Macs. It is not signed with a Developer ID or notarized by Apple, so Gatekeeper will not automatically allow it to run. If macOS refuses to open it, build from source on your Mac or wait for a properly signed and notarized release.

Release assets include a macOS DMG, a Windows installer, and `SHA256SUMS`.
