# MDEdit 功能迭代规划

更新日期：2026-09-28 · 已发布版本：v0.5.1 · 开发中：v0.6.0

## 已发布：v0.2.0 功能批次

1. **代码块预览高亮**：按围栏代码块的语言标识及常见别名着色；无标识或无法识别时显示普通代码文本。预览处理继续在 Worker 中完成，不让长代码块阻塞编辑。
2. **快捷工具栏**：增加表格行列选择并插入 GFM 表格；标题菜单提供正文与 H1～H5，切换级别时替换当前标题标记。Markdown 中已有的 H6 仍正常预览。
3. **多标签**：可新建、打开、切换和关闭文档；同一路径只保留一个标签。各标签独立保存编辑位置、保存状态、恢复草稿与磁盘冲突信息；关闭未安全保存的标签时保留可恢复内容。
4. **文档标题大纲**：根据当前标签的 H1～H6 实时生成层级视图；切换标签后同步切换大纲，点击标题定位到正文。

本批次还包含编辑区与预览区同步定位、预览代码块复制，以及列表、任务项、引用和围栏代码块的快捷插入。v0.2.1 更新了应用图标。

## 版本功能范围

1. **文件夹树与跨文件搜索**：用户选择本地文件夹后，按层级浏览并打开 Markdown 文档；树中突出当前标签。搜索仅覆盖该文件夹内的 Markdown 文件，结果显示文件路径和命中片段并可跳转。文件夹树首阶段只负责浏览与打开，暂不提供重命名、移动和删除。
2. **图片粘贴与相对路径管理**：粘贴或拖入本地图片后，将图片保存到当前文档可访问的位置，并插入相对路径；未命名文档先确定保存位置。处理重名与文件写入失败，避免留下失效链接。
3. **深色模式**：支持跟随系统及手动切换；编辑器、预览、代码高亮、表格和侧栏使用一致的配色。
4. **Mermaid 与公式**：识别标记为 `mermaid` 的围栏代码块，在预览中渲染为图表；同时渲染行内公式和块级公式。图表或公式的语法错误只影响对应内容，不中断整篇文档的预览。
5. **导出 PDF/HTML**：导出当前文档时保留表格、代码高亮、本地图片以及已支持的 Mermaid 和公式呈现；明确输出文件及资源的保存方式。
6. **列表格式扩展**：快捷菜单提供无序列表、数字编号的有序列表和任务列表；对选中的多行可按所选类型转换，有序列表按顺序连续编号。其他列表样式在详细设计时确认。

## 建议版本分配

| 版本 | 功能范围 |
| --- | --- |
| **v0.3.0** | 文件夹树、跨文件搜索、深色模式、列表格式扩展。 |
| **v0.4.0** | 图片粘贴与相对路径管理、Mermaid 和公式预览。 |
| **v0.5.0** | 导出 PDF/HTML，保留前述版本已支持的图片、图表和公式。 |
| **v0.6.0** | 写作效率：专注模式与打字机模式、目录增强、表格内编辑。 |
| **v0.6.1** | 界面整理：精简顶栏与格式工具栏、改善阅读宽度和字号、减少重复标签与视觉噪声。 |
| **v0.7.0** | PDF 导出设置：纸张尺寸、页边距与按一级标题分页。 |

按“文件夹树 → 跨文件搜索”、“图片与扩展预览 → 导出”的依赖顺序设计和验收。v0.6.0 先完善日常写作与编辑操作；v0.6.1 整理现有界面的呈现与入口；v0.7.0 再扩展 PDF 输出控制。各功能版本之间如需修复问题，使用对应的补丁号（例如 v0.5.1）；v0.6.1 不增加新的文档能力。v0.2.1、v0.3.0、v0.4.0、v0.5.0 和 v0.5.1 的 macOS 安装包均为临时签名试用包；v0.5.0 的 macOS 安装包存在启动失败问题，应使用 v0.5.1。正式发行仍需 Developer ID 签名与 Apple 公证。后续版本具体发布日期未定。

## v0.6.1 界面整理

按以下优先级设计和验收，保持现有文件操作、格式命令、快捷键、保存状态与错误提示可用。

1. **顶栏减负**：顶栏保留新建、打开、保存等常用入口；另存为、HTML/PDF 导出归入文件菜单。文件名以标签为主要展示位置，顶栏保留清晰的保存状态；未保存、保存失败和磁盘冲突仍须醒目可见。
2. **工具栏分组**：直接展示标题、粗体、斜体、链接等高频格式命令；表格、列表、引用和代码块归入“插入”菜单。侧栏切换、预览切换、专注/打字机模式和主题设置保持稳定位置，窗口变窄时避免工具栏堆成多行。
3. **编辑与阅读排版**：适当提高源码编辑字号，限制预览正文的最大阅读宽度并居中；在分栏、隐藏预览和显示侧栏时保持合理的文本宽度与留白。
4. **减少重复标识**：精简“编辑器 / MARKDOWN”“实时预览 / PREVIEW”等重复标题，收敛非必要的分隔线、背景层次和强调色，让正文成为视觉中心。
5. **统一细节**：统一侧栏和状态栏的小字号、灰阶及控件间距；同时检查浅色与深色主题的可读性、悬停、选中和键盘焦点状态。

验收时检查常规窗口与当前最小窗口宽度下的布局，不出现控件遮挡或无法访问的命令；用键盘可到达收起后的操作；已有快捷键、保存/冲突反馈及主要写作流程保持正常。

## 后续版本功能范围

1. **专注模式与打字机模式**：专注模式淡化非当前段落；打字机模式在输入时将当前光标行保持在编辑区固定位置。可分别启用或关闭，不改变文档内容。
2. **目录增强**：在现有标题跳转基础上，标示当前所在章节，并支持筛选标题和折叠层级，便于长文档定位。
3. **表格内编辑**：在现有表格插入功能上，支持用 Tab 在单元格间移动、在末尾单元格追加行，以及增加或删除行列和设置列对齐。
4. **PDF 导出设置**：允许选择常用纸张尺寸和页边距，并可设置一级标题从新页开始；导出继续包含当前已支持的图片、图表和公式。

## 暂不纳入上述批次

文件夹内的重命名、移动、删除，所见即所得编辑，云同步、多人协作及插件系统。后续可根据用户反馈另行评估。
