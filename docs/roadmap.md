# MDEdit 功能迭代规划

更新日期：2026-09-24
基线版本：v0.1.1
状态：当前优化批次代码已实现，待桌面交互验收；下个迭代范围已确认

## 当前优化批次

1. **代码块预览高亮**：按围栏代码块的语言标识及常见别名着色；无标识或无法识别时显示普通代码文本。预览处理继续在 Worker 中完成，不让长代码块阻塞编辑。
2. **快捷工具栏**：增加表格行列选择并插入 GFM 表格；标题菜单提供正文与 H1～H5，切换级别时替换当前标题标记。Markdown 中已有的 H6 仍正常预览。
3. **多标签**：可新建、打开、切换和关闭文档；同一路径只保留一个标签。各标签独立保存编辑位置、保存状态、恢复草稿与磁盘冲突信息；关闭未安全保存的标签时保留可恢复内容。
4. **文档标题大纲**：根据当前标签的 H1～H6 实时生成层级视图；切换标签后同步切换大纲，点击标题定位到正文。

本批次也纳入编辑区与预览区同步定位、预览代码块复制，以及列表、任务项、引用和围栏代码块的快捷插入。

## 下一个迭代版本

1. **文件夹树与跨文件搜索**：用户选择本地文件夹后，按层级浏览并打开 Markdown 文档；树中突出当前标签。搜索仅覆盖该文件夹内的 Markdown 文件，结果显示文件路径和命中片段并可跳转。文件夹树首阶段只负责浏览与打开，暂不提供重命名、移动和删除。
2. **图片粘贴与相对路径管理**：粘贴或拖入本地图片后，将图片保存到当前文档可访问的位置，并插入相对路径；未命名文档先确定保存位置。处理重名与文件写入失败，避免留下失效链接。
3. **深色模式**：支持跟随系统及手动切换；编辑器、预览、代码高亮、表格和侧栏使用一致的配色。
4. **Mermaid 与公式**：在预览中渲染图表、行内公式和块级公式；语法错误只影响对应内容，不中断整篇文档的预览。
5. **导出 PDF/HTML**：导出当前文档时保留表格、代码高亮、本地图片以及已支持的 Mermaid 和公式呈现；明确输出文件及资源的保存方式。

建议按“文件夹树 → 跨文件搜索”、“图片与扩展预览 → 导出”的依赖顺序设计和验收。版本号与具体发布节奏尚未确定。

## 暂不纳入上述批次

文件夹内的重命名、移动、删除，所见即所得编辑，云同步、多人协作及插件系统。

市场功能依据见 [Markdown 编辑器功能调研](research/2026-09-24-markdown-editor-market.md)。
