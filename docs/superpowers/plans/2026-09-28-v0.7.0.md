# v0.7.0 PDF 导出设置实现计划

> **面向 AI 代理的工作者：** 按任务顺序在当前隔离工作树内实现，每个行为先写失败测试，再写实现。

**目标：** 让 PDF 导出支持纸张、页边距和一级标题分页，并发布 v0.7.0。

**架构：** 用共享的有限选项类型与校验函数约束渲染进程、IPC 和主进程。主进程在现有独立 HTML 打印链路中生成 PDF 专用分页 CSS；文件菜单收集并保存用户选择。

**技术栈：** Electron 38、React 19、TypeScript、Vitest。

**规格：** [v0.7.0 PDF 导出设置设计](../specs/2026-09-28-v0.7.0-pdf-export-design.md)。

## 全局约束

- 纸张：A4、A5、Letter；页边距：10、18、25 mm；默认 A4、18 mm、关闭一级标题分页。
- HTML 导出保持原有表现。PDF 继续使用经过净化的 Markdown 内容、独立隐藏窗口和原子写入。
- 主进程在打印或写入前校验来自 IPC 的选项。

---

## 文件与职责

- `src/shared/pdf-export-options.ts`：选项类型、默认值、校验及有限 CSS 生成。
- `tests/pdf-export-options.test.ts`：选项和分页样式的行为测试。
- `src/main/export-document.ts`：把已校验的 PDF 设置注入打印 HTML，指定打印尺寸。
- `src/shared/contracts.ts`、`src/preload/index.ts`、`src/main/index.ts`：传递 PDF 设置。
- `src/renderer/App.tsx`、`src/renderer/styles.css`：文件菜单中的 PDF 设置与本地偏好。
- `README.md`、`docs/releases/v0.7.0.md`、`package.json`、`package-lock.json`：使用说明、发布说明和版本。
