# MDEdit v0.4.0 实现计划

**目标：** 完成 [v0.4.0 功能设计](../specs/2026-09-25-v0.4.0-design.md) 中的图片导入、Mermaid 与公式预览。

## 实施步骤

1. 在主进程实现批量图片导入、格式和路径校验、失败回滚，并通过共享契约与 preload 暴露给编辑区。
2. 在 CodeMirror 接入粘贴和拖入事件。未命名文档先保存，导入期间锁定编辑器，成功后一次插入所有相对图片链接。
3. 在预览 Worker 中解析并渲染公式；在预览界面逐个渲染 Mermaid 代码块，处理主题变化和局部错误。
4. 更新样式、版本号、README、规划状态与发布说明，运行类型检查和构建校验。
