# v0.7.1 文档搜索与界面语言实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（- [ ]）语法来跟踪进度。

**目标：** 文档内搜索面板整齐、可在窄窗口操作；应用内界面支持默认英文和可持久切换的简体中文。

**架构：** src/shared/language.ts 保存双语字典和格式化函数；渲染进程持有语言状态并同步给单窗口主进程和预览 Worker。CodeMirror 继续负责搜索状态与命令，自定义面板只负责输入、布局和翻译。

**技术栈：** Electron、React 19、CodeMirror 6、TypeScript、Vitest、electron-builder。

**规格：** docs/superpowers/specs/2026-09-29-v0.7.1-search-language-design.md

## 全局约束

- 首次安装及无效语言偏好选择 en；仅支持 en、zh-CN。
- 切换语言不重写文档、草稿、路径或已有编辑内容；选项显示 English、简体中文。
- 760×520 窗口在侧栏与预览同时显示时，搜索面板无水平溢出、所有操作可访问。
- 保持 ⌘/Ctrl+F、Enter、Shift+Enter、Esc、大小写、正则、整词和替换语义。
- 版本 v0.7.1 的发布说明注明 macOS DMG 临时签名、未经 Apple 公证。

## 文件结构

- src/shared/language.ts：语言类型、字典、参数格式化、解析。
- src/renderer/search-panel.ts：CodeMirror 面板 DOM、查询同步、命令绑定。
- src/renderer/App.tsx、WorkspaceSidebar.tsx、styles.css：语言设置、React 文案和布局。
- src/renderer/preview.ts、preview.worker.ts、mermaid-preview.ts：预览中应用生成的文字。
- src/main/*.ts、src/shared/contracts.ts、src/preload/index.ts：主进程语言同步、默认文件名和错误文案。
- tests/language.test.ts：解析、字典键、参数与错误；scripts/smoke-search-language.mjs：打包应用交互。
- package.json、package-lock.json、README.md、docs/roadmap.md、docs/releases/v0.7.1.md：版本与用户说明。

- [ ] 步骤 3：实现 Language、parseLanguage、messages、text；英文键为类型基准，中文用 Record 约束。静态和动态键覆盖顶栏、菜单、格式、PDF、侧栏、草稿、状态、预览、搜索、错误和无障碍名称。

~~~ts
export type Language = 'en' | 'zh-CN'
export type MessageKey = keyof typeof english
export function parseLanguage(value: string | null): Language {
  return value === 'zh-CN' ? 'zh-CN' : 'en'
}
export function text(language: Language, key: MessageKey, values: Record<string, string | number> = {}): string {
  return messages[language][key].replace(/\{([a-zA-Z]+)\}/g, (_, name: string) => String(values[name] ?? '{' + name + '}'))
}
~~~

- [ ] 步骤 4：重跑该测试和 npm run typecheck，提交任务 1。
