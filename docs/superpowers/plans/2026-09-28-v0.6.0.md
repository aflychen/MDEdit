# v0.6.0 写作效率实现计划

> **面向 AI 代理的工作者：** 按任务内的复选框跟踪进度；在当前会话中逐任务实施并检查结果。

**目标：** 交付专注与打字机模式、可筛选和折叠的当前章节目录，以及 GFM 表格内编辑。

**架构：** 纯函数处理段落范围、目录可见性和表格文本变换；CodeMirror 扩展与 React 控件调用这些函数。表格识别复用 remark 的 GFM 解析，以排除围栏代码及其他非表格文本。

**技术栈：** Electron、React、CodeMirror 6、remark-gfm、TypeScript、Vitest。

**规格：** `docs/superpowers/specs/2026-09-28-v0.6.0-design.md`。

## 全局约束

- 模式、目录操作不改变 Markdown 文件内容。
- 表格结构变更保留原始单元格 Markdown；遇到可能丢失内容的输入时不执行变更。
- 文件保存、草稿恢复、磁盘冲突和预览安全机制继续使用现有路径。
- 功能发布版本是 v0.6.0，路线图的“已发布版本”仅在正式发布后更新。

## 文件职责

- `src/renderer/writing-mode.ts`：段落边界与 CodeMirror 专注/打字机扩展。
- `src/renderer/outline-navigation.ts`：目录当前项、搜索和折叠规则。
- `src/renderer/table-editing.ts`：GFM 表格定位、单元格导航和结构变更。
- `src/renderer/WorkspaceSidebar.tsx`：目录搜索、折叠和当前章节交互。
- `src/renderer/App.tsx`：模式开关、编辑器扩展、表格命令和目录位置联动。
- `src/renderer/styles.css`：两种主题下的模式、目录和表格控件样式。
- `tests/writing-mode.test.ts`、`tests/outline-navigation.test.ts`、`tests/table-editing.test.ts`：对应的真实文本行为测试。
- `README.md`、`docs/releases/v0.6.0.md`、`package.json`、`package-lock.json`：使用和版本说明。
