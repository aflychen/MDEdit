# MDEdit v0.3.0 实现计划

> 面向 AI 代理的工作者：按任务执行，重要行为先写失败测试，再实现并验证。

**目标：** 交付文件夹树、跨文件搜索、深色模式和列表格式扩展。

**架构：** 主进程以一次系统文件夹选择建立临时授权，集中处理目录列举、文件打开和搜索。渲染进程只接收安全的目录项和搜索结果；主题与列表转换保持在渲染进程。

**技术栈：** Electron、React、TypeScript、CodeMirror 6、Vitest。

**规格：** [v0.3.0 功能设计](../specs/2026-09-24-v0.3.0-design.md)。

## 全局约束

- 用户原有 `.md` 文件仍是正式来源；保留多标签、恢复草稿和磁盘冲突行为。
- 文件夹树只负责浏览和打开；搜索仅覆盖授权文件夹内的 Markdown 文件。
- 文件夹 API 拒绝静态符号链接和根目录外路径；本地进程持续替换路径时的竞态限制见规格。

## 文件职责

- `src/main/workspace-folder.ts`：文件夹授权、按需列举、受限打开路径、全文搜索。
- `src/main/index.ts`、`src/preload/index.ts`、`src/shared/contracts.ts`：对话框和跨进程 API。
- `src/renderer/WorkspaceSidebar.tsx`：文件树、搜索结果、键盘可用的侧栏 UI。
- `src/renderer/App.tsx`：侧栏集成、搜索跳转、列表命令和主题设置。
- `src/renderer/markdown-commands.ts`、`src/renderer/theme.ts`、`src/renderer/styles.css`：列表转换和三种主题。
- `tests/workspace-folder.test.ts`、`tests/markdown-commands.test.ts`、`tests/theme.test.ts`：关键行为测试。
