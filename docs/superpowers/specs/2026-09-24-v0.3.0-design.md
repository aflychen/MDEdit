# MDEdit v0.3.0 功能设计

日期：2026-09-24

## 范围

实现 [迭代规划](../../roadmap.md) 中分配给 v0.3.0 的文件夹树、跨文件搜索、深色模式和列表格式扩展。当前打开的 `.md` 文件继续由现有多标签和自动保存机制管理。

## 文件夹与搜索

- 用户通过系统对话框选择一个本地文件夹。文件侧栏按需展开子文件夹，只显示文件夹及 `.md` 文件，并突出当前标签对应的文件。切换文件夹后清除旧树和搜索结果；已经打开的标签继续可用。
- 文件夹授权只在本次应用会话有效。主进程保存对话框返回的真实根路径；目录列举、从树中打开文档、全文搜索都通过该授权。拒绝绝对路径、父目录穿越、符号链接，以及真实路径逃出根目录的请求。树只负责浏览和打开。
- 文件系统校验覆盖打开前后及保存前的常见路径变化；Node 的路径式读写无法原子绑定父目录，另一个本地进程若持续在系统调用之间替换目录，仍有竞态风险。正式安全边界需要平台级目录句柄操作；本批次不承诺抵御此类本地并发攻击。
- 搜索不区分大小写，覆盖当前文件夹内的 Markdown 文件；同一行的多个命中分别返回相对路径、行号、列号、命中片段及文件内容指纹。点击结果打开或聚焦对应标签；磁盘版本与搜索时一致且当前编辑缓冲区中命中所在行未变时，跳到记录的位置，否则提示重新搜索。每次最多返回 100 个命中；超过时显示截断提示。超过 5 MiB、无法读取或不是有效 UTF-8 的文件跳过并显示跳过数量。空查询不执行扫描。

## 深色模式

- 工具栏提供“跟随系统／浅色／深色”设置，偏好保存在本机。系统模式响应系统外观变化。
- 编辑器、预览、代码高亮、表格、标签、侧栏、弹出层和状态区采用对应配色，保持文字与控件可辨识。主题切换不改变文档内容和标签状态。

## 列表格式

- 快捷菜单提供无序列表、数字有序列表、任务列表。光标所在行或选中的多行会转换成所选格式；已有列表标记会被替换，保留正文和缩进。
- 有序列表从 1 开始连续编号；不同缩进层级分别编号。空行保持不变。没有正文的单行产生可继续输入的列表标记。
