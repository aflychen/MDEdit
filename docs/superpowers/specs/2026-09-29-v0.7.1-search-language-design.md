# v0.7.1 文档搜索与界面语言设计

## 目标与范围

让文档内查找与替换面板的输入框、操作和选项在常规及最小窗口宽度下清晰对齐；提供 English 与简体中文两种完整的应用内界面语言。新安装及未保存语言偏好的旧安装默认 English。用户在“View / 视图”菜单中选择“Language / 语言”后立即切换，重启后仍保留选择。文档内容、文件名、路径和用户输入不参与翻译。

本次覆盖应用拥有的可见文案和无障碍名称：顶栏、菜单、格式工具、标签、草稿恢复、侧栏、文档内搜索、工作区搜索、编辑与预览标识、状态栏、导出设置、提示、确认文案、应用生成的错误和预览占位。应用新插入的表格表头等默认占位词按当前语言生成，已有正文不重写。系统提供的打开与保存对话框控件跟随操作系统语言；第三方或操作系统返回的原始诊断细节可保留原文，但应用提供的说明和操作建议使用所选语言。搜索及保存逻辑、文档数据格式和快捷键不改变。

## 方案选择

1. 只给 CodeMirror 默认搜索栏改 CSS 并注入翻译：修改量小，但语言切换时已打开面板的静态按钮文案无法可靠即时更新，且默认 DOM 布局限制明显。
2. **采用：保留 CodeMirror 的搜索状态与命令，自定义它的面板视图。** 由现有搜索扩展处理查询、选中、替换与高亮；新面板只负责布局、输入和命令调用。这样能统一中英文、明暗主题和窄窗口布局，不重写搜索算法。
3. 独立于 CodeMirror 实现一套 React 搜索：布局自由，但需要重复实现匹配、替换、选中与编辑器同步，回归风险和维护成本更高。

## 文档内搜索面板

面板固定在源码编辑区顶部，使用与应用菜单相同的圆角、边框、间距和焦点样式。查找输入占据首行主要空间，前一个、后一个和关闭操作位于相邻的按钮组；空间不足时按钮组换至下一行，不产生横向滚动。独立的轻量选项行提供大小写、正则、整词切换，以及“Replace / 替换”展开入口。展开后显示替换输入和“Replace / 替换”“Replace All / 全部替换”操作。按钮文本与提示随语言更新，图标按钮提供可翻译的 `aria-label` 和 `title`。替换区域默认收起，打开和收起只改变面板，不改变当前查询。

继续支持 ⌘/Ctrl+F 打开并选中查找输入，Enter 查找下一个、Shift+Enter 查找上一个、Esc 关闭，及原有大小写、正则、整词、单次替换、全部替换语义。切换语言时保留打开状态、查询、替换文本、选项和当前编辑器选择。切换标签时按现有编辑器状态机制保留各标签的查询。错误的正则表达式不执行替换，并给出所选语言的简短提示。面板在最小窗口 760×520、侧栏与预览同时显示时仍能完整访问所有操作。

## 语言状态与边界

语言类型固定为 `en` 和 `zh-CN`。渲染进程从 `localStorage` 的 `mdedit-language` 读取：缺失、无效或读取失败时使用 `en`；选择后即时写回，写入失败时本次会话仍切换。页面 `lang` 与日期格式随语言同步，语言选项始终以 `English` 和 `简体中文` 自称。单窗口主进程默认 `en`，接收经过校验的语言设置 IPC，以便应用生成的文件默认名、导出对话框说明和错误提示与界面一致。用户打开文件之前不会修改文件内容或文件名。

文案集中在有类型约束的双语字典中，动态数量、文件路径、快捷键和错误参数使用明确的格式化函数。两个语言包必须具有相同的键。React 界面使用当前语言生成文案；侧栏显式接收语言或翻译接口。预览 Worker 接收语言以生成应用自有的图片占位文案，语言切换时重新渲染当前预览。应用错误沿用现有错误代码判断逻辑，给用户展示的消息按稳定消息标识翻译；未知系统错误显示所选语言的通用说明及原始诊断。现有草稿、主题、PDF 设置和标签会话保持原样。

## 验收与发布

- 默认首次打开为 English；选择简体中文后立即更新已打开搜索面板及整个应用内界面，重启仍为中文；损坏或未知的偏好回退为 English。
- 查找、前后跳转、大小写、正则、整词、替换及全部替换在两种语言下结果一致；快捷键、关闭和标签切换不丢查询或文档内容。
- 浅色与深色主题，以及 760×520 的侧栏加预览布局中，搜索面板没有水平溢出、控件遮挡或不可达操作；键盘焦点可见。
- 应用自己的菜单、工具栏、侧栏、草稿恢复、状态、提示、错误和预览占位在 English 下无遗留中文；文件内容、路径和系统原始诊断不作为翻译缺口。
- 增加语言解析、双语字典完整性和搜索面板关键交互的自动验证；运行仓库要求的测试、类型检查、Worker 检查、macOS 签名构建与打包应用冒烟验收。发布为 v0.7.1，附双语说明并注明 macOS DMG 临时签名、未经 Apple 公证。
