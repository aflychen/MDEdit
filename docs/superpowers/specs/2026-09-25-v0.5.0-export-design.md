# v0.5.0 导出设计

## 范围

在当前文档提供 HTML 和 PDF 导出。两种格式都使用当前编辑器内容，包含 GFM 表格、代码高亮、本地图片、Mermaid 图表和 KaTeX 公式。导出不修改 Markdown 文件，也不要求先保存当前改动；尚未保存的新文档可以导出没有本地图片的内容。

## 输出

HTML 为单文件，内嵌样式、公式字体、本地图片和图表 SVG；PDF 从同一 HTML 页面由 Electron 打印生成。两种格式均使用适合阅读及打印的浅色主题，PDF 为 A4。远程图片沿用预览中的受限占位提示。无法读取的本地图片导致导出失败并显示原因，以免生成缺失资源的文件。

## 数据流与安全

渲染进程在点击导出时用现有 Markdown 管道生成经过净化的 HTML，在临时连接到页面的容器内解析本地图片、渲染 Mermaid，随后销毁容器。主进程通过专用 IPC 弹出保存对话框。HTML 原子写入目标；PDF 仅在无脚本、无网络访问的隐藏窗口中载入临时 HTML 并打印，再原子写入目标。导出页面设置限制性 CSP，不执行文档中的脚本。保存对话框取消时不写文件。

## 交付

更新界面、IPC、文档、版本号及发布工作流。macOS v0.5.0 继续使用临时签名，Windows 提供 NSIS 安装包。发布时提供 SHA256SUMS。
