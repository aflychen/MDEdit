# Markdown 编辑器本轮功能设计

日期：2026-09-24
状态：已按用户确认的功能范围进入实现

## 目标与边界

在 v0.1.1 的本地 Markdown 编辑器上增加代码块预览高亮、表格与标题快捷操作、多文档标签和当前文档标题大纲。文件夹树、跨文件搜索、图片粘贴、深色模式、导出、Mermaid 和公式属于下个迭代，见 [功能规划](../../roadmap.md)。继续以用户原有的 `.md` 文件为正式来源，不改变现有的恢复草稿、磁盘冲突与预览安全边界。

## 预览与目录

- 围栏代码块仅根据显式语言标识及常见别名高亮；不猜测未声明的语言。无法识别的语言显示普通代码文本。语言标记与高亮输出在清理后仍可用于 CSS 着色，文档内容不能借高亮注入可执行 HTML。
- 解析 Markdown 时同时提取 H1～H6 的可见文字、层级和源码行号。代码块中的 `#` 不产生大纲项。大纲只用于应用导航，不向 `.md` 文件插入非标准目录语法。
- 预览 Worker 的结果同时带文档 ID 和修订号。只接受当前标签的最新结果，避免标签切换后显示其他文档的预览、大纲或字数。
- 大纲可折叠，随当前标签更新；点击条目把编辑器光标移到标题并滚动到可见区域。编辑区与预览区可在同一文档中按标题位置同步定位；同步时避免互相触发滚动循环。

## 工具栏

- 标题菜单提供正文、H1～H5。对当前标题切换级别时替换行首标记；对普通行添加标题标记；选中文本时保留正文内容与选区语义。
- 表格入口选择至少 1 列、1 行正文，插入带表头和分隔线的合法 GFM 表格，光标进入首个表头单元格。源文档仍由 CodeMirror 编辑，不引入所见即所得表格编辑器。
- 现有粗体、斜体、行内代码、链接、查找按钮保持可用。增加列表、任务项、引用和围栏代码块的快捷插入；预览代码块可复制源码内容。

## 多标签与文件权限

- 新建、打开和相对 Markdown 链接在当前窗口形成标签；同一路径只保留一个标签并聚焦它。标签显示文件名、活动状态和未保存或异常状态，支持切换、关闭与常见快捷键。
- 每个标签独立拥有文档文本、修订号、保存状态、恢复草稿、光标/编辑器状态和预览。离开标签不清空未保存内容；后台标签仍应自动保存和写恢复草稿。关闭标签前先确保内容已保存或已有可恢复草稿，失败时让用户决定是否继续关闭。
- 主进程不再以单个 `activePath` 授权所有操作。只允许已通过打开对话框、系统文件打开、最近文件或受限相对链接打开的路径参与保存与资源读取；保存、图片读取、相对链接解析都绑定发起操作的文档路径。每个打开文件独立监视外部变化，关闭后撤销其访问和监听。
- 同一路径的重复打开不能重置该路径的磁盘基线，避免掩盖外部改动。磁盘变化只更新对应标签的冲突状态。保存和草稿写入的异步结果只更新发起它们的标签。
- 应用关闭前备份所有未落盘标签的草稿。首个多标签版本不恢复上次打开的完整标签布局，仍可从现有恢复草稿入口恢复文本。

## 验证

1. 预览测试覆盖多语言/别名、未知语言回退、高亮清理、H1～H6 大纲和代码块内伪标题。
2. 编辑命令测试覆盖标题升降/转正文、表格行列与光标位置、列表等快捷插入。
3. 标签状态测试覆盖重复路径聚焦、后台文档更新、关闭后活动标签选择和独立冲突状态；文件服务测试覆盖打开两个路径后交替保存及单路径冲突。
4. 运行 `npm test`、`npm run typecheck`、`npm run test:worker`；检查构建后的 Worker 仍在无 DOM 环境工作。
