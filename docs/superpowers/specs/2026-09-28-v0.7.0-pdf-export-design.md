# v0.7.0 PDF 导出设置设计

## 范围

在“文件”菜单的 PDF 导出入口旁提供纸张、页边距和一级标题分页设置。纸张可选 A4、A5、Letter；页边距可选窄 10 mm、标准 18 mm、宽 25 mm。默认 A4、标准页边距、不按一级标题分页，保持现有 PDF 输出。记住本机上次选择，导出时使用当前设置。HTML 导出不受这些设置影响。

## 数据与打印

渲染进程把 PDF 选项作为独立参数通过现有导出 IPC 发送。主进程严格校验每个枚举和布尔值，用有限选项生成 `@page` 的尺寸与页边距，并将所选尺寸交给 `printToPDF`。分页启用时，在打印样式里让非文档首元素的一级标题从新页开始；首个元素本来就是一级标题时不生成空白首页。现有 Markdown 净化、本地图片、图表、公式、隐藏窗口隔离、保存对话框及原子写入流程继续使用。

## 验收

不同纸张与页边距产生对应页面尺寸和内容区域；开关只影响 PDF 的一级标题分页。无效 IPC 参数在写入前失败。取消保存时不创建文件，HTML 输出与既有行为一致。覆盖选项校验和样式生成的自动测试，并在本地检查生成的安装包。
