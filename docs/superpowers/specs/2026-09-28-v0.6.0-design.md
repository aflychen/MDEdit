# v0.6.0 写作效率设计

## 范围

按照 `docs/roadmap.md` 的 v0.6.0 批次，完善专注模式、打字机模式、目录导航和 GFM 表格编辑。继续使用现有的 Markdown 源码编辑与独立预览，不改变文件保存、恢复草稿和预览安全边界。

## 编辑器模式

- 工具栏分别切换专注模式和打字机模式，两种模式可以同时启用。模式只影响当前窗口的显示和滚动，不写入 Markdown。
- 专注模式淡化当前光标所在段落以外的编辑行。段落按空行与 Markdown 块起始行划分；空行上的光标就近选择相邻段落。选中文本仍保持可辨识。
- 打字机模式在输入导致文档改变时将光标行移至编辑区中部；点击、搜索和滚动不强制重新居中。切换标签后，各文档保留原有编辑位置。

## 目录导航

- 目录标示当前章节。编辑器移动光标、滚动或预览滚动时，用该位置之前最近的标题确定章节；文首无标题时不标示。
- 目录提供标题筛选和逐级折叠。筛选结果显示匹配标题及其祖先，并临时展开命中的折叠分支。切换文档后清空筛选和折叠状态。
- 目录按钮继续跳转到源码标题；筛选和折叠不修改文档。

## 表格编辑

- 在现有表格入口中加入当前表格的行、列和对齐操作。命令仅在光标位于 GFM 表格时启用；围栏代码中的相似文本不被识别为表格。
- Tab / Shift-Tab 在表头及正文单元格间前进或后退，并跳过分隔行。在最后一个正文单元格按 Tab 时追加一行；只有表头时，在表头末尾按 Tab 追加首个正文行。
- 支持在当前行之后插入正文行、删除当前正文行、在当前列右侧插入列、删除当前列，以及将当前列设为默认、左、中或右对齐。单列表格不能删掉最后一列。
- 变更表格结构时规范化该表格的管道符和空格，保留单元格内的原始 Markdown 内容。解析异常或会丢失额外单元格的表格不执行结构变更。

## 验收

针对段落边界、目录筛选/折叠与当前章节、表格导航和结构变更编写行为测试。运行项目测试、类型检查和构建，并在可用的桌面环境检查浅色与深色界面。
