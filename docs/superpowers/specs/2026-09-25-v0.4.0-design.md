# MDEdit v0.4.0 功能设计

日期：2026-09-25

## 范围

按照 [迭代规划](../../roadmap.md) 实现图片粘贴和拖入、相对路径管理、Mermaid 图表以及行内与块级公式预览。保持现有多标签、恢复草稿、自动保存和预览的本地资源限制。

## 图片导入

- 在编辑区粘贴或拖入 PNG、JPEG、GIF、WebP、AVIF 图片。多张图片按原顺序导入；拖入位置是落点，粘贴位置是当前选区。
- 未命名文档先通过现有“另存为”确定 `.md` 路径；取消时不创建图片。图片保存在文档同级的 `images/` 目录，用随机文件名规避重名，插入 `![描述](images/文件名)`。只在全部写入成功后修改正文。
- 主进程验证格式特征、单张 10 MiB 和批量总量，拒绝符号链接图片目录。批量导入中途失败时删除本次已创建的文件。编辑区在导入期间锁定，避免选区或标签变化。
- 图片链接仍服从现有的本地预览规则：只读取文档目录内的相对路径；远程图片不自动加载。原图片文件不移动或删除。

## Mermaid 与公式

- 将标记为 `mermaid` 的围栏代码块逐个渲染成图表。渲染失败的块显示局部错误和原始图表代码，不影响其它块或正文。按当前明暗主题重绘。
- 用 `remark-math` 解析 `$...$` 和 `$$...$$`，先消毒 Markdown 转换结果，再由 KaTeX 在预览 Worker 内产生公式 HTML。禁用 KaTeX 的可信 HTML 扩展并限制公式展开与尺寸。无效公式显示局部错误文本。
- Mermaid 使用严格安全级别；Markdown 仍先经过现有 HTML 消毒。图表渲染发生在预览 DOM 已更新后，旧预览的异步结果不覆盖新预览。
